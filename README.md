# Finance Automation Portfolio

Five deep, interactive finance products by Guilherme Chehade at the
intersection of FP&A, finance data, systems, automation and applied AI.

**Public portfolio:** https://finance-automation-portfolio.vercel.app

**Release status:** v4 is implemented and validated locally. The public URL
continues to show the prior release until publication is explicitly approved.

## Cases

1. **P&L Performance Dashboard** - 1,296 YTD dimensional records across nine
   markets, four brands and six channels; derived statements, reconciled bridges,
   driver classification, formula lineage and variance-pack workflow.
2. **Forecast Planning Workspace** - eight connected drivers, 12 monthly periods,
   capacity and headcount constraints, guardrails, review rationale and version history.
3. **Finance Data Control Tower** - four reproducible incidents, staged execution,
   governed remediation, financial reconciliation and a blocking release gate.
4. **AI Variance Intelligence Copilot** - claim-level evidence, numerical checks,
   degraded-source scenarios, editable drafts and controlled distribution.
5. **AI Finance Controls Agent** - 18 risk-ranked exceptions, read-only tool traces,
   mutable review workflow, prompt-injection defense and zero autonomous postings.

## Transparency

The solution patterns and capabilities reflect real professional work. Every
company name, value, volume, timeline and impact metric shown in this public
portfolio is synthetic and illustrative. No employer data, proprietary source
code or confidential business logic is included.

## Stack

React, TypeScript, Vite, Recharts and Lucide icons. A shared interaction layer
provides confirmation dialogs, drawers, accessible toasts, session persistence
and audit timelines. The demos are deterministic client-side simulations and do
not connect to employer systems, email services or external AI models.
